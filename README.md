# Dungeon AI SaaS — Инструкция по деплою

## Что это
Полноценный веб-сервис с авторизацией, оплатой через ЮКассу и AI-игрой на Claude API.
Пользователи могут:
- Регистрироваться и входить
- Пополнять баланс токенов через ЮКассу (рублями)
- **Добавить свой API ключ Anthropic** и играть без списания баланса
- Сохранять игровые прогрессы в облаке

---

## Шаг 1 — Получить Anthropic API ключ (серверный)

1. Зайди на **console.anthropic.com**
2. Зарегистрируйся (нужна зарубежная карта или виртуальная)
   - Альтернатива для РФ: **aitunnel.ru** — покупаешь доступ за рубли
3. API Keys → **Create Key**
4. Скопируй ключ (начинается с `sk-ant-...`)

Это серверный ключ — он используется для пользователей без своего ключа (которые платят токенами).

---

## Шаг 2 — ЮКасса (оплата)

1. Зарегистрируйся на **yookassa.ru**
   - Можно как физлицо-самозанятый (комиссия ~3.5%)
   - Или как ИП (комиссия ~2.8%)
2. После верификации: Настройки → **API ключи**
3. Скопируй **ShopID** и **Секретный ключ**
4. В настройках укажи Webhook URL:
   `https://ВАШ_ДОМЕН/api/payment/webhook`

## Шаг 3 — Деплой на Railway

### 3.1 Подготовь GitHub репозиторий
```bash
cd dungeon-saas
git init
git add .
git commit -m "init"
# Создай репо на github.com и запушь:
git remote add origin https://github.com/ВАШ_ЮЗЕР/dungeon-ai.git
git push -u origin main
```

### 3.2 Создай проект на Railway
1. Зайди на **railway.app** → New Project
2. Deploy from GitHub repo → выбери свой репозиторий
3. Railway автоматически определит Node.js

### 3.3 Добавь базу данных
1. В проекте Railway: **+ New** → **Database** → **PostgreSQL**
2. Railway автоматически создаст переменную `DATABASE_URL`

### 3.4 Установи переменные окружения
В Railway → твой сервис → **Variables** → добавь:

| Переменная | Значение |
|---|---|
| `ANTHROPIC_API_KEY` | `sk-ant-api03-...` (серверный ключ) |
| `JWT_SECRET` | Любая длинная случайная строка (32+ символа) |
| `YOOKASSA_SHOP_ID` | ID из ЮКассы |
| `YOOKASSA_SECRET_KEY` | Секретный ключ из ЮКассы |
| `APP_URL` | `https://ВАШ_ПРОЕКТ.railway.app` |
| `PRICE_PER_1K_TOKENS` | `2` (рублей за 1000 токенов) |
| `MIN_TOPUP` | `100` |

### 3.5 Деплой
Railway автоматически задеплоит при пуше в GitHub.
Первый деплой: база данных инициализируется через `npm run db:init`.

## Функция "Свой API ключ"

Пользователи могут в Личном кабинете → **"🔑 Свой API ключ Anthropic"** вставить
свой ключ `sk-ant-...` от console.anthropic.com.

- Ключ проверяется живым запросом к Anthropic перед сохранением
- Хранится в БД в поле `own_api_key`
- При наличии ключа баланс **не тратится** — запросы идут через аккаунт пользователя
- Ключ можно удалить в любой момент → тогда снова используется баланс

Это полезно для технически продвинутых пользователей, у которых уже есть ключ.

### API эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET | `/api/auth/me` | Текущий пользователь |

| GET | `/api/ai/usage` | Статистика токенов |

| POST | `/api/payment/webhook` | Вебхук от ЮКассы |
| GET | `/api/payment/history` | История платежей |
| GET | `/api/payment/prices` | Пакеты токенов |
| GET/POST/DELETE | `/api/saves/:slot` | Облачные сохранения |

## Безопасность

- **Helmet** — HTTP security headers
- **Rate limiting** — 120 req/min общий, 20 req/min на AI
- **JWT** авторизация с 30-дневным токеном
- **bcryptjs** (cost 12) для хранения паролей
- **Атомарные SQL транзакции** при списании токенов
- **Идемпотентность** вебхука ЮКассы — двойного начисления нет
- **Валидация API ключа** перед сохранением (живой запрос к Anthropic)
- CORS ограничен до `APP_URL`

## Экономика

| Расход | Стоимость |
|---|---|
| Claude Sonnet (вход) | $3 / 1M токенов |
| Claude Sonnet (выход) | $15 / 1M токенов |
| Средний запрос ~1500 токенов | ≈ $0.015 |

**Пример при цене 2₽/1000 токенов:**
- Пользователь пополняет на 100₽ → получает 50,000 токенов
- Тратит на ~33 запроса (игровые сессии)
- Себестоимость: ~$0.5 = ≈45₽
- Прибыль: ~55₽ с 100₽ пополнения

## Возможные проблемы

**"ANTHROPIC_API_KEY не задан"** → Проверь переменные в Railway

**ЮКасса не принимает webhook** → URL должен быть доступен из интернета (не localhost)

**База не инициализируется** → Проверь что `DATABASE_URL` задан и PostgreSQL поднят

**"Ключ недействителен"** при сохранении своего ключа → Проверь что ключ активен на console.anthropic.com и пополнен баланс Anthropic
